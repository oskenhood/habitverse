# HabitVerse · демо-версия (один HTML-файл)

Полностью автономная версия приложения: **ни сети, ни сборки, ни зависимостей**.
Все данные хранятся в `localStorage` браузера.

## Как запустить

**Вариант А — просто открыть**
Дважды кликните по `HabitVerse-demo.html`. Всё работает, включая анимации, графики и звук.

> Ограничение: при открытии через `file://` браузер не даст установить PWA и может не выдать
> разрешение на уведомления. Для этого используйте вариант Б.

**Вариант Б — локальный сервер (рекомендуется)**
```bash
cd habitverse/demo
python3 -m http.server 8080
# → http://localhost:8080
```
Теперь работают: установка как приложение (PWA), Service Worker, push-разрешения.

**Вариант В — исходники**
`demo/index.html` + `demo/styles.css` + `demo/app.js` — то же самое, но раздельно (удобно править).
`HabitVerse-demo.html` собирается из них скриптом (см. `build-single-file` ниже).

## Что есть в демо

**Привычки**
- создание / редактирование / дублирование / удаление / архив
- эмодзи-иконка: 7 категорий × ~100 эмодзи + свой символ
- 16 цветов + произвольный цвет через color-picker
- описание, категория, сложность ★1–5, цель в единицах (страниц/минут/стаканов)
- живой предпросмотр карточки прямо в модалке
- расписание: каждый день · выбранные дни недели (5 пресетов) · каждые N дней · раз в неделю · числа месяца · дата старта
- сортировка (выше/ниже), перетаскивание порядка через меню

**Отметки**
- 4 состояния по клику: ✓ выполнено → ⤼ осознанный пропуск → ✕ провал → сброс
- отметки **за прошлые даты** (backfill) — из таблицы недели, календаря или heatmap
- количество + заметка к каждому дню
- стрики: текущий и рекордный (пропуск со статусом ⤼ стрик не рвёт)

**Сегодня**
- кольцо прогресса, KPI-полоса (лучший стрик, всего отметок, % за 30 дней, уровень/XP)
- **3D-сфера постоянства** на CSS 3D: три вращающихся кольца, пульсирующее ядро, частицы по числу привычек
- мотивационная цитата (20 штук, кнопка ✨ в топбаре — полноэкранный поп-ап)
- таблица недели 12 × 7 с кликабельными ячейками

**Календарь**
- месячная сетка: точки по привычкам, % за день, полоса заполнения, подсветка сегодняшнего дня
- фильтр по одной привычке
- **heatmap года** (365 дней, 5 уровней) — клик открывает месяц
- панель дня: отметить/снять любую привычку за любую прошлую дату
- сводка месяца: выполнение, отметки, идеальные дни, серия 100%

**Отчёты**
- 6 KPI с дельтой к прошлому периоду
- динамика за 7/30/90/180/365 дней + скользящее среднее (canvas, анимация отрисовки)
- пончик статусов (выполнено / пропуск / провал)
- столбцы по дням недели (план vs факт)
- **радар сфер жизни** по 8 категориям
- рейтинг привычек и стриков
- карта года
- **персональные инсайты**: оценка ритма, лучший/худший день недели, слабое звено, опора, рекорд стрика, баланс сфер, слепая зона, серия идеальных дней
- 20 достижений (4 уровня редкости) с подсветкой полученных
- экспорт **CSV** и **JSON**, печать отчёта

**Блокнот**
- заметки: заголовок, текст, теги, 6 цветов фона, закрепление, привязка к привычке
- markdown-lite: `# ## ###`, `**жирный**`, `*курсив*`, `` `код` ``, `- список`, `[[2026-10-06]]`
- поиск и фильтр по тегам, живой предпросмотр разметки

**Челленджи и друзья (механики HabitLink)**
- создание челленджа: привычка + срок (7…90 дней) + код-приглашение + цвет/эмодзи
- карточка: прогресс, место в рейтинге, участники-аватары, победитель после завершения
- вступление по коду, лист участников с heatmap
- **лидерборд** по XP за 30 дней (вы + команда)
- экипаж: 4 демо-друга, «пинки мотивации», удаление
- **лента активности**: свои и чужие отметки, стрики, идеальные дни, уровни, ачивки, челленджи; кнопка «симулировать активность»

**Кабинет**
- имя, описание, **дата рождения** (возраст + «ДР через N дней»)
- аватар: загрузка фото (сжатие до 256 px, data-URL) или 30 эмодзи
- 5 тем: Полночь / Бездна / Неон / Графит / Светлая (кнопка 🎨 в сайдбаре переключает по кругу)
- 16 акцентных цветов, плотность (обычная/компакт), звуки, начало недели
- напоминания: разрешение браузера, тестовое уведомление, время ежедневной сводки
- приватность ленты и профиля
- экспорт/импорт JSON, загрузка демо-данных, полный сброс, «выйти»
- размер занятого хранилища

**Прочее**
- онбординг из 4 шагов (имя → аватар → демо-данные или чистый лист)
- XP и уровни (порог ×1.32), confetti, Web Audio-звуки (отклик, уровень, ачивка)
- фоновые частицы на canvas, реагирующие на курсор
- 3D-tilt карточек при наведении
- хоткеи: `N` — новая привычка, `1…7` — разделы, `/` — поиск, `Esc` — закрыть
- PWA: `manifest.webmanifest` + `sw.js` (офлайн-кэш, push-обработчики, действия «Открыть» / «✓ Готово»)
- адаптив от 360 px, мобильное меню, `prefers-reduced-motion`

## Демо-данные

При первом запуске онбординг предложит **«Загрузить демо-данные»** — это:
13 привычек в 7 категориях (две из них — типа «🚫 не делать»), реалистичная история за **90 дней** (дисциплина растёт к сегодняшнему дню),
4 заметки, 2 челленджа (один активный, один завершённый), 4 друга, ~70 событий ленты, начисленные XP и ачивки.

Перегенерировать: **Кабинет → 🎲 Демо-данные**. Очистить: **Кабинет → 🗑 Сбросить всё**.

## Напоминания в демо

Напоминания срабатывают, **пока вкладка открыта** (тик каждые 20 секунд):
- по времени конкретной привычки — только в дни её расписания (или каждый день, если выбран такой режим);
- вечерняя сводка в заданное время — «Осталось N из M».

Настоящий Web Push с закрытым браузером — в полной версии (`../app`, Supabase Edge Function + VAPID + pg_cron).
Обработчики `push` и `notificationclick` в `sw.js` уже написаны и совместимы с ней.

## Отличия демо от полной версии

| | Демо | Полная версия (`../app`) |
|---|---|---|
| Хранилище | `localStorage` одного браузера | Supabase Postgres + RLS |
| Аккаунт | онбординг без пароля | e-mail/пароль, Google, GitHub, magic-link |
| Синхронизация | нет | между всеми устройствами |
| Друзья | смоделированы | реальные пользователи, заявки, поиск |
| Лента | локальная + симуляция | Realtime (Supabase Channels) |
| Push | только при открытой вкладке | Web Push через Edge Function + cron |
| Аватар | data-URL в localStorage | Supabase Storage |
| 3D | CSS 3D-сфера | three.js / React Three Fiber |
| Деплой | файл на диске | Vercel |

## Сборка single-file из исходников

```bash
cd habitverse
python3 - <<'PY'
import os
d='demo'
html=open(f'{d}/index.html',encoding='utf-8').read()
css=open(f'{d}/styles.css',encoding='utf-8').read()
js=open(f'{d}/app.js',encoding='utf-8').read()
html=html.replace('<link rel="manifest" href="manifest.webmanifest">','')
html=html.replace('<link rel="stylesheet" href="styles.css">','<style>\n'+css+'\n</style>')
html=html.replace('<script src="app.js"></script>','<script>\n'+js+'\n</script>')
open('HabitVerse-demo.html','w',encoding='utf-8').write(html)
print('готово', round(os.path.getsize('HabitVerse-demo.html')/1024,1),'КБ')
PY
```
