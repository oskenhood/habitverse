## Часть 1. Что у вас в руках

**HabitVerse 2.1** — личный дашборд продуктивности: трекер привычек по мотивам HabitLink,
но **без paywall** (все привычки и друзья бесплатны) и **без геймификации** (никаких XP, уровней,
ачивок, конфетти — осознанное решение).

| Раздел | URL | Что умеет |
|---|---|---|
| Обзор | `/` | метрики дня/недели, «На сегодня» с циклом отметок, стрики, мысль дня |
| Привычки | `/habits` | фильтры, поиск, строки с историей 14 дней, квоты, заморозки, DnD-сортировка за ручку, ⋯-меню |
| Календарь | `/calendar` | сетка месяца с точками статусов, панель дня, отметки задним числом, heatmap года, сводка месяца |
| Отчёты | `/reports` | диапазоны 7–365 дней, 5 KPI с дельтой, 4 диаграммы, рейтинг, стрики, карта года, инсайты, CSV, печать |
| **Финансы** | `/finance` | реестр расходов «дата / тип / наименование / сумма» с быстрой формой, итоги день-неделя-месяц, 4 KPI, пьедестал топ-3 с цитатами, разбивка по типам, названия по убыванию, экспорт CSV |
| Заметки | `/notes` | карточки с мини-разметкой (жирный/курсив/списки/цитаты/`[[теги]]`), поиск, закрепление |
| Команда | `/team` | челленджи (создание/код приглашения/прогресс), лидерборд за 30 дней, экипаж, лента с реакциями |
| Настройки | `/settings` | имя (аватар-инициалы), демо-данные, **экспорт/импорт JSON-бэкапа**, сброс |
| Каталог | модалка | 30 готовых привычек в 7 группах, защита от дублей |
| ⌘K | везде | палитра команд: разделы, создание (привычка/заметка/челлендж/**запись расходов**), поиск по привычкам и заметкам, оформление, экспорт |
| Виджет заметок | везде | плавающая иконка на правой кромке: hover → закреплённые и свежие заметки |
| Онбординг | первый визит | 4-шаговый мастер: приветствие → имя → аватар-эмодзи → демо-данные или чистый лист (с открытием каталога) |

**Оформление:** 8 мягких пастельных акцентов × светлый/тёмный режим, плотность интерфейса —
всё в меню 🎨 в шапке или через ⌘K → «Оформление».

**Где живут данные:** в localStorage браузера, ключ `habitverse.v1` (та же схема, что у демо —
экспортные файлы взаимно совместимы). Это значит:

- ✅ Работает без сервера и интернета (после загрузки страницы), мгновенно, приватно.
- ⚠️ Данные **привязаны к браузеру и домену**: другой браузер/устройство их не увидит.
- ⚠️ Очистка данных сайта в браузере удалит их → **делайте бэкап** (Часть 4).
- 🔜 Аккаунты, облачная синхронизация, реальные друзья и напоминания — фазы 5.4–5.5.
  До тех пор раздел «Команда» работает в демо-режиме (друзья смоделированы).

## Часть 2. Запуск локально (режим разработки)

### 2.1. Что понадобится

| Что | Версия | Проверить |
|---|---|---|
| Node.js | **20.9+** (лучше 22 LTS) | `node -v` |
| npm | 10+ (идёт с Node) | `npm -v` |

### 2.2. Три команды

```bash
cd habitverse/web
npm install
npm run dev          # → http://localhost:3000
```

Первый запуск встретит пустыми состояниями: нажмите **«Загрузить демо-данные»**
(13 привычек, 90 дней истории, команда, челленджи, заметки) или **«Каталог»**, чтобы собрать своё.

> Альтернатива из корня репозитория (корневой `package.json` проксирует команды в `web/`):
> ```bash
> cd habitverse && npm run install:all && npm run dev
> ```

## Часть 3. Продакшен: сборка, экспорт, деплой

### 3.1. Серверная сборка (Next.js-сервер)

```bash
cd habitverse/web
npm run build        # = next build --webpack  (Turbopack в слабой среде ловит SIGKILL — не используйте)
npm run start        # → http://localhost:3000; другой порт: npm run start -- -p 8080
```

Ожидание: `✓ Compiled successfully`, 10 маршрутов, все помечены `○ (Static)`.

### 3.2. Статический экспорт (любой хостинг без Node-сервера)

```bash
cd habitverse/web
npm run export       # = HV_EXPORT=1 next build --webpack → папка web/out/
```

В `out/` — полностью готовый статический сайт: каждый маршрут лежит папкой с `index.html`
(`trailingSlash: true`), поэтому **rewrite-правила хостингу не нужны**. Работает на GitHub Pages,
Netlify Drop, любом nginx/Python-сервере.

Проверить локально:

```bash
cd habitverse/web/out && python3 -m http.server 8080   # → http://localhost:8080
```

⚠️ Двойным кликом по `out/index.html` сайт **не** запустится — нужен любой HTTP-сервер
(модули и RSC-запросы идут по сети).

### 3.3. Деплой на Vercel (рекомендуемый)

Переменные окружения **не нужны**, база данных **не нужна** — сайт полностью клиентский.

1. Репозиторий опубликован: **[github.com/oskenhood/habitverse](https://github.com/oskenhood/habitverse)**,
   ветка `main` (код уже на GitHub; дальнейшие правки — через `git push` из папки `habitverse/`).
2. [vercel.com](https://vercel.com) → **Add New… → Project** → импортируйте репозиторий.
3. В настройках импорта: **Root Directory = `web`**, Framework Preset определится сам (Next.js),
   команды сборки не трогайте.
4. **Deploy**. Через ~минуту получите `https://ваш-проект.vercel.app`.
5. (Опционально) **Settings → Domains** — подключить свой домен.

Каждый `git push` = автоматический redeploy. Данные пользователей живут в их браузерах,
сервер Vercel раздаёт только статику — бесплатный план подходит без ограничений.

### 3.4. GitHub Pages / Netlify

- **Netlify:** перетащите папку `web/out/` на [app.netlify.com/drop](https://app.netlify.com/drop) — готово.
- **GitHub Pages:** соберите `npm run export`, опубликуйте содержимое `web/out/`
  (ветка `gh-pages` или артефакт Actions); в Settings → Pages включите HTTPS.

## Часть 4. Данные и бэкап

| Действие | Где | Что делает |
|---|---|---|
| **Экспорт JSON** | Настройки → Данные → «Экспорт JSON» | скачивает `habitverse-export-YYYY-MM-DD.json` — **полный бэкап**: привычки, лог отметок, заметки, челленджи, профиль |
| **Импорт JSON** | Настройки → Данные → «Импорт JSON» | выбираете файл бэкапа → подтверждаете → данные **полностью заменяются** содержимым файла |
| Экспорт CSV | Отчёты → «Экспорт CSV» | плоская таблица отметок (для Excel/анализа); для восстановления не подходит |
| Демо-данные | Настройки → «Загрузить демо-данные» | заменяет всё на реалистичный сценарий (90 дней) |
| Сброс | Настройки → «Сбросить всё» | очищает данные (с подтверждением) |

**Рекомендации:**

- Делайте экспорт JSON **раз в неделю** (например, по пятницам) и после больших изменений.
- Файл бэкапа совместим с демо (`HabitVerse-2.0.html`, ключ `habitverse.v1`) — можно открыться
  в демо и наоборот; перенос между браузерами/устройствами = экспорт на одном → импорт на другом.
- Повреждённый файл импорт не примет: вы увидите предупреждение, текущие данные останутся целы.

## Часть 5. Как пользоваться (короткая карта)

- **Отметки:** клик по дню — цикл `выполнено → пропуск → провал → пусто`. В «На сегодня» и в
  календаре работают отметки за любые прошедшие даты.
- **Стрики:** считаются только по плановым дням; незакрытый сегодняшний день стрик **не рвёт**;
  провал можно заморозить (бюджет заморозок — в карточке привычки, восстанавливается каждый месяц).
- **Привычка «не делать»:** в карточке включите негативный режим — день без отметки считается успехом.
- **Порядок:** в «Привычках» перетаскивайте строки за ручку ⠿ (работает и пальцем).
- **⌘K (Ctrl+K):** всё быстрее — переходы, создание привычки/заметки/челленджа, поиск, смена темы.
- **Виджет заметок:** иконка на правой кромке есть на каждой странице; наведение показывает
  закреплённые и свежие заметки, клик открывает заметку на весь экран.
- **Финансы:** раздел «Финансы» в сайдбаре — реестр трат и итоги; вторая точка входа — чип
  «Реестр трат» в строке привычки категории «Финансы» (и пункт в её ⋯-меню). Периоды
  день/неделя/месяц переключаются чипами, стрелки листают прошлые периоды, «Текущий» возвращает
  к сегодняшнему. Тип расхода — пресет или свой (подсказки в выпадающем списке).
- **Первый визит:** откроется мастер онбординга (имя, аватар, демо-данные или чистый лист).
  Пройти заново: Настройки → сброс данных (или очистка localStorage сайта).
- **Темы:** меню 🎨 в шапке — 8 акцентов × светлый/тёмный, плотность.

## Часть 7. Troubleshooting

| Симптом | Причина и лечение |
|---|---|
| `EADDRINUSE: port 3000` | Порт занят: `npm run dev -- -p 3001` (или `npm run start -- -p 3001`). В песочнице ассистента старые `next start` живут фоном — всегда брать свежий порт |
| Сборка молча убита (`Killed`, exit 137) | Нехватка RAM. Используйте только `npm run build` (он с `--webpack`); Turbopack (`next build` без флага) в среде ~1 ГБ умирает |
| Данные пропали | Проверьте, что вы на том же домене/порту и не чистили данные сайта. Восстановитесь из JSON-бэкапа (Часть 4) |
| Изменения не видны после `npm run start` | `next start` раздаёт старую сборку — пересоберите: `rm -rf .next && npm run build` |
| `out/` открыли двойным кликом — белый экран | Статике нужен HTTP-сервер (см. 3.2) |
| Импорт JSON говорит «в файле нет списка привычек» | Файл не является экспортом HabitVerse (или повреждён) — данные не тронуты |
| Хочу старую версию с Supabase | Архив: `app/` (v1.2) + `docs/ИНСТРУКЦИЯ-app-v1.2.md`; миграции — `supabase/` |

## Приложение. Все команды одним блоком

```bash
# ── разработка ──────────────────────────────────────────
cd habitverse/web && npm install && npm run dev            # http://localhost:3000

# ── продакшен (сервер) ──────────────────────────────────
cd habitverse/web && npm run build && npm run start

# ── продакшен (статика) ─────────────────────────────────
cd habitverse/web && npm run export                        # → web/out/
cd habitverse/web/out && python3 -m http.server 8080       # локальная проверка

# ── тесты (из tests/) ───────────────────────────────────
cd habitverse/tests && npm install
npm run test:web && npm run test:v2 && npm test            # быстрые наборы
cd ../web && npm run build && cd ../tests && npm run test:web:smoke   # смоук против сборки
cd ../web && npm run export && cd ../tests && npm run test:web:static # смоук против статики

# ── чистка артефактов ───────────────────────────────────
rm -rf habitverse/web/.next habitverse/web/out habitverse/web/tsconfig.tsbuildinfo
```
