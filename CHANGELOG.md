## [2.1.0] — 2026-10-09

**Заезд F-2 «Финансы» + онбординг** (план из WEEKLY 2026-10-08-release-2.0.0, решения пользователя
подтверждены: финансы — «оба» размещения, онбординг — перенести из демо). Версия `2.0.0 → 2.1.0`
(`VERSION`, `web/package.json`, корневой `package.json`, `APP_VERSION` в `engine.ts`).

### Добавлено
- **Раздел «Финансы» (`/finance`)** — F-2 из отзыва Максима: «импровизированный Excel» расходов.
  - **Реестр**: таблица «дата / тип / наименование (вольный текст) / сумма» + форма быстрой записи
    прямо над таблицей (как строка Excel: после добавления дата и тип остаются, курсор — в следующем
    наименовании). Правка — модалка (`ExpenseModal`), удаление — с подтверждением. Экспорт CSV реестра.
  - **Итоги день / неделя / месяц**: переключатель периода + стрелки «предыдущий/следующий» и кнопка
    «Текущий»; 4 KPI (итого, в среднем в день, самый затратный тип, рекорд периода).
  - **Пьедестал 1-2-3** (порядок 2-1-3, медали, разная высота): топ-3 траты периода, каждая —
    с «цитатой пользователя» (наименование в вольной форме и есть цитата), суммой, типом и датой.
    «Главное чтоб не список» — выполнено.
  - **«Куда уходят деньги»**: разбивка по типам с долями-барами, самый затратный тип сверху.
  - **«Названия по убыванию»**: агрегат одинаковых наименований (×N записей, сумма, тултип
    с крупнейшей записью), топ-8.
  - Типы расходов: 12 пресетов (`EXPENSE_TYPES`, у каждого stroke-иконка и мягкий цвет) + свои
    через datalist (цвет по стабильному хешу). Хранение типа — строкой в нижнем регистре.
- **Второе размещение F-2 — быстрый доступ из привычек категории «Финансы»**: чип «Реестр трат»
  в строке привычки, пункт «Финансы: открыть реестр» в меню «⋯», кнопка «Реестр трат» в шапке
  страницы «Привычки» (когда есть активная money-привычка).
- **Онбординг в web** — порт 4-шагового мастера из демо: приветствие → имя → аватар-эмодзи (18) →
  «демо-данные» или «с чистого листа». Полноэкранный при первом визите (`profile.onboarded`),
  после «чистого листа» сам открывает каталог привычек; в хроме — stroke-иконки вместо эмодзи
  (эмодзи только в сетке аватаров — пользовательский контент, правило DESIGN 1b).
- **Движок** (`engine.ts`): сущность `Expense` + `expenses[]` в `HvState` (старые бэкапы без поля —
  `normalize` достраивает `[]`, импорт/экспорт JSON совместим); `finPeriod/finShift/finLabel`
  (неделя Пн–Вс, високосный февраль), `finSummary` (итоги, byType, topNames, пьедестал),
  `fmtMoney` («1 234,5 ₽»), `addExpense/updateExpense/removeExpense` (валидация ДО мутации),
  `expensesBetween`, `buildExpensesCsv`, `expenseTypeStyle`, `capFirst`, `ONB_EMOJI`.
  В `seedDemo` — 16 детерминированных расходов за ~4 недели (включая оммаж отзыву:
  «Жёстко навернул габаджоу в китайке»).
- **Стор** (`store.ts`): `hv.addExpenseBy/updateExpenseById/removeExpenseById/exportExpensesCsv/
  finishOnboarding` — ошибки валидации возвращаются текстом для тоста.
- **Навигация**: «Финансы» в `SECTIONS` (сайдбар + шапка, иконка coin), команда «Новая запись
  расходов» в ⌘K, поддержка `/finance?new=1` и `?period=day|week|month`.
- **Тесты**: секция 12 в `engine.web.test.js` (+15: периоды, високосный февраль, сдвиги, подписи,
  fmtMoney, валидация CRUD, normalize-совместимость, агрегаты, пьедестал, CSV, seed-расходы) —
  **89 ok**; смоук-секции «/finance» (10), «/habits: быстрый доступ» (3), «онбординг» (8) —
  **62 ok**; `loadPage` смоука научился пустому localStorage (`{ storage: null }`);
  в статик-тесте маршрут `/finance/` — **6 ok**.

### Изменено

  теперь expense-экспорты исключены, остальные xp/level/achiev/confetti/sfx по-прежнему под запретом.
- `ИНСТРУКЦИЯ.md`, `README.md`, `web/README.md`, `PROTOCOL.md`, `docs/PORT_PLAN.md`, `BACKLOG.md` —
  синхронизированы: раздел «Финансы», онбординг, 10 маршрутов, счётчики тестов 89/62/6.

### Персист и границы

### 🔴 Критическое исправление: сборка падала из-за three.js

`next build` завершался **SIGKILL** — build worker убивался по памяти. Бисекцией
(отключение импорта 3D-сцены) установлено: причина в `three` + `@react-three/fiber` + `@react-three/drei`
(~1.5 МБ исходников в графе сборки). На машинах с <2 ГБ RAM сборка не проходила вовсе,
на Vercel росло время и память билда.

**Решение — смена архитектуры 3D:**
- пакеты `three`, `@react-three/fiber`, `@react-three/drei`, `@types/three` **удалены из зависимостей**;
- `src/components/3d/sphere-scene.tsx` (R3F) удалён;
- добавлен `src/components/3d/three-sphere.tsx` — «чистый» three.js **без типов пакета**
  (описаны только используемые поверхности API), подгружаемый **с CDN по требованию**;
- `ProgressSphere` по умолчанию рисует лёгкую CSS 3D-сферу, а WebGL включается
  переключателем «3D: CSS / 3D: WebGL» (выбор хранится в `localStorage`);
- результат: сборка проходит за ~30 с, размер `node_modules` 801 МБ → **636 МБ**.

Побочный плюс: демо и прод теперь визуально совпадают (в демо всегда была CSS-сфера).

- Supabase: 12 таблиц, RLS на всё, 25 политик, триггеры, функции `current_streak()`, `habit_stats()`, `award_xp()`, `unlock_achievement()`, `search_users()`, `join_challenge_by_code()`, `finish_expired_challenges()`, `recalc_challenge_score()`
- Авторизация: e-mail/пароль, Google, GitHub, magic-link, сброс пароля
- Web Push: VAPID-подписка, Edge Function `send-reminders` (режимы reminders/digest), pg_cron и Vercel Cron
- PWA: manifest, Service Worker (офлайн-кэш оболочки, push, notification actions), shortcuts, иконки 192/512
- Защита маршрутов через `proxy.ts` (конвенция Next 16), заголовки безопасности

**UX**
- Glassmorphism, 3D-tilt карточек, Framer Motion-переходы, фоновые орбы и частицы на canvas (реагируют на курсор)
- Web Audio-звуки: отклик, уровень, достижение
- Хоткеи: `N` — новая привычка, `1…7` — разделы, `/` — поиск, `Esc` — закрыть
- Адаптив от 360 px, мобильное меню, `prefers-reduced-motion`
- Анти-FOUC: тема применяется скриптом до гидратации
