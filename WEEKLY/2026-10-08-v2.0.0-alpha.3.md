## Что принёс заезд
1. Ревью пользователя (скриншоты 5–6): «текст друг в друге» в списке разделов и перегруженный каталог с эмодзи.

3. Диагноз скриншота 6: реальный баг — CSS каталога жил только в `demo/styles.css`, в v2 правил `.preset` не было.

5. Поднят вопрос переноса с одностраничного демо на полноценный сайт (Next.js) — план см. в `docs/PORT_PLAN.md`.

## Сделано (код)
- ⌘K: иконки через `icon()`, цветные точки `.dot` для акцентов/привычек, глифы убраны.
- Каталог переписан: группы со small-caps заголовком и счётчиком, строки с плиткой категории (SVG на тоне цвета),
  чипы расписания и недельной цели, кнопка «+», состояние «уже есть», stagger-появление, поиск с иконкой.
- 6 новых SVG-иконок категорий (heart, case, bolt, palette, leaf, coin); теги/селекты/превью/инсайты без эмодзи категорий.
- Тосты: SVG по типу; инсайты: плашки `.ins-ic` с SVG.
- Сайдбар: версия сборки в подвале; `.ic` = `font-size:0; overflow:hidden` (текст-«fallback» больше не пролезет).
- Экспорты: `window.toast`, в `HV` добавлены `toast, icon, ICON_PATHS, APP_VERSION`; дубль строки экспортов убран.

- **Взято сразу:** small-caps заголовки групп со счётчиком; мета-чипы справа (расписание/квота); stagger списков;
  мягкие tint-плитки под иконки; ховеры 100–150 ms без движения.
