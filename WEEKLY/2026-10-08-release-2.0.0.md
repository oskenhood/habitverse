## Что сломалось / грабли

- 🔴 **5 сиротских `next-server`** (порты 3111/3222/3333/3444/3456) с прошлых сессий + выживший
  python http.server ели RAM → demo-тесты дважды падали с `Killed`. Решение: `/proc/<pid>/cmdline`
  читается, `kill <PID>` работает (в отличие от отсутствующих `ps`/`pkill`). Все убиты — тесты зелёные.
- 🔴 **Грабля №55:** маркер готовности в jsdom-смоуке обязан быть клиентским. `#setName` на /settings
  есть в SSR-HTML → проверки стартовали до гидратации, React не реагировал. Правильный маркер
  настроек — «… КБ в localStorage» (появляется только после ready).
- `python3 -m http.server` + undici (node fetch) = `ERR_ASSERTION !this.paused` на keep-alive —
  для тестов статики написан свой node-сервер (`tests/static-server.js`).
