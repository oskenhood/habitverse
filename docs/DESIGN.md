# HabitVerse 2.0 — дизайн-система

Принцип: **личный дашборд продуктивности**, а не игра. Спокойно, плотно, типографично.
Ориентир по духу — Notion, Linear, Things 3. Никакого неона, конфетти и свечения.

### Привычки: мягкая палитра (вместо кислотной)
`#C0714F #A9853F #5F8A6B #3F8A80 #4A76A8 #7A6AA8 #A85C74 #6B6E76 #8A6B5F #5F7A8A #8A5F6B #6B8A5F`

### Типографика
- Стек: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`
- Моно для цифр: `ui-monospace, "SF Mono", "JetBrains Mono", Menlo, monospace` + `font-variant-numeric: tabular-nums`
- Шкала: `11 / 12 / 13 / 14 / 16 / 20 / 24 / 32 px`
- Заголовки: `font-weight 600`, `letter-spacing -0.02em`
- Метки (uppercase): `11px`, `weight 600`, `letter-spacing 0.06em`, цвет `--text-3`
- Межстрочный: `1.5` для текста, `1.25` для заголовков

### Радиусы, тени, отступы
- Радиусы: `4px` (чипы, инпуты sm) · `6px` (кнопки, инпуты) · `8px` (карточки) · `12px` (модалки)
- Тени: почти нет. `--shadow-1: 0 1px 2px rgba(16,16,16,.04)` · `--shadow-2: 0 4px 12px rgba(16,16,16,.06)` ·
  `--shadow-pop: 0 8px 28px rgba(16,16,16,.12)` (только модалки/поповеры)
- Отступы: сетка 4px. Базовый шаг `16px`, между секциями `32px`, отступ страницы `24–32px`
- Плотность: строка списка `40–44px`, карточка привычки `~64px`

### Анимация
- Длительности: `120ms` (hover) · `180ms` (состояния) · `240ms` (раскрытие) · `320ms` (переход страницы)
- Кривая: `cubic-bezier(0.2, 0, 0, 1)` — быстрая в начале, мягкая в конце
- Что анимируем: появление строк (fade + 4px сдвиг), раскрытие меню, смену раздела, прогресс
- Что НЕ анимируем: пульсацию, свечение, вращение, масштаб >1.03, bouncing

## 1b. Иконки и аватары (правило alpha.2)

**Эмодзи в UI-хроме запрещены.** Все служебные значки — единый набор stroke-SVG
(`ICON_PATHS` + `icon(name, size)` в `v2/app.js`): 39 иконок, viewBox 24×24,
`stroke-width 1.7`, `stroke-linecap/linejoin: round`, `fill: none`.
Размеры: 11–13px в тегах/пилюлях, 14–15px в кнопках, 16px в шапке, 26–30px в empty-состояниях.

Эмодзи допускаются **только как пользовательский контент**: иконка привычки, иконка челленджа,
реакции в ленте, выбор аватара при онбординге (до загрузки фото).

**Аватары:** `avatarHtml(person, size)` — круг, инициал (первая буква имени), фон и цвет текста —
`color-mix` одного из 8 приглушённых тонов (`AV_HUES`) с поверхностью, тон выбирается по хешу имени
(стабильно между рендерами). Градиенты и эмодзи в аватарах запрещены. Фото пользователя — `img` в том же круге.

## 2. Структура (IA)

```
┌─────────────────────────────────────────────────────────────┐
│ ШАПКА: ◈ HabitVerse │ Обзор Привычки Календарь Отчёты Заметки│
│        Команда │           ⌘K поиск   🎨 тема   [аватар] ▾   │
├──────────┬──────────────────────────────────────────────────┤
│ САЙДБАР  │  Хлебные крошки                                   │
│ (дерево, │  Заголовок раздела + действия                     │
│ сворач.) │  ────────────────────────────────────────────     │
│          │  Контент                                          │
└──────────┴──────────────────────────────────────────────────┘
```

Разделы: **Обзор** (сегодня) · **Привычки** (таблица/доска/календарь — виды как в Notion) ·
**Календарь** · **Отчёты** · **Заметки** (блочный редактор) · **Команда** (челленджи, друзья, лента) ·
**Настройки**.

Сайдбар — разделы + «Быстрые действия» + карточка пользователя (по ревью alpha.2 список привычек
из сайдбара убран: дублировал раздел «Привычки» и шумел). Сворачивается в узкую полоску.
Hover-действия у строк привычек: drag-handle, правка, `⋯`.

## 3. Что удалено из v1.x (геймификация)

XP, уровни и их бейджи, таблица достижений, confetti, Web Audio-звуки, 3D-сфера,
фоновые орбы и canvas-частицы, 3D-tilt карточек, неоновые glow-тени, shimmer-блики,
«идеальный день +25 XP», всплывающие тосты про уровень.

**Осталось по смыслу, но подано спокойно:** стрики (текущий/рекорд), % выполнения,
heatmap, недельная квота, заморозки, негативные привычки, заметки, челленджи, лидерборд, лента.

## 5. Исследование референсов (alpha.3)

Смотрели открытые макеты и продукты: Notion «Sidekick» personal dashboard, Notion-inspired page (Figma community),
Onrise и HABITABI (habit trackers), минималистичные UI-киты. Выжимка:

| Приём | Источник | Решение |
|---|---|---|
| Small-caps заголовки групп с счётчиком справа от названия группы | Sidekick | ✅ каталог alpha.3 (`.cat-head`) |
| Мета-информация чипами справа от названия строки | Sidekick | ✅ чипы расписания и квоты (`.chip`) |
| Stagger-появление строк списка (10–20 ms на строку) | Onrise | ✅ каталог (`--d`), уже было у привычек/заметок |
| Мягкая tint-плашка под иконкой сущности (цвет сущности при 12–14% плотности) | HABITABI | ✅ `.tile`, `.ins-ic`, `.sheet-ic` |
| Ховеры 100–150 ms только сменой тона, без движения | Notion | ✅ у нас `--t-fast` на hover-фонах |
| Underlined-табы с маленькой иконкой вместо сегмент-контролов | Sidekick | 💡 P2-16 |
| Tint-бар секции на всю ширину (uppercase + иконка) | Sidekick | 💡 P2-17 |
| Правая rail-колонка со сводками (ширина ~300 px) | Sidekick | 💡 P2-17 |
| Ghost-кнопка «+ New» в конце списка | Sidekick | 💡 P2-18 |
| Крупные пастельные карточки-блоки во весь ряд | Onrise | ❌ не берём: ломает плотность дашборда |
| Иллюстрации-обложки проектов | Sidekick | ❌ не берём: нет контентных обложек |

Правило из исследования: **анимация = тон и 2–4 px сдвига, максимум 320 ms**; всё, что двигается сильнее,
выглядит «игрушечно» рядом с Notion-классом.
