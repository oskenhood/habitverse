# HabitVerse 2.0

**Личный дашборд продуктивности** — трекер привычек по мотивам HabitLink: стрики с заморозками,
гибкое расписание, недельные квоты, отметки задним числом, календарь с heatmap, отчёты с диаграммами,
заметки с мини-разметкой, челленджи с друзьями, лента с реакциями, каталог из 30 пресетов,
8 мягких тем × 2 режима, ⌘K. **Без paywall и без геймификации** — осознанные решения.

> 🟢 **Основной проект — [`web/`](web)** (Next.js 16 + React 19 + TypeScript, версия **2.1.0**).
> Данные живут в браузере (localStorage), экспорт/импорт JSON-бэкапа — в Настройках.
> Запуск: `cd web && npm install && npm run dev` → http://localhost:3000.
> Продакшен-сборка, статический экспорт и деплой на Vercel — **[`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md)**.

## Быстрый старт

```bash
cd habitverse/web
npm install
npm run dev        # http://localhost:3000 — на первом экране «Загрузить демо-данные»
```

## Продакшен

```bash
cd habitverse/web
npm run build && npm run start    # Next-сервер
npm run export                    # статический сайт в web/out/ — любой хостинг без Node
```

Деплой на Vercel: импорт репозитория, **Root Directory = `web`**, переменные окружения не нужны —
пошагово в [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md), часть 3.

## 🔄 Как мы работаем дальше

У ассистента нет памяти между разговорами — преемственность живёт в файлах
(подробно — [`PROTOCOL.md`](PROTOCOL.md), состояние — [`HANDOFF.md`](HANDOFF.md)).

| Вы говорите | Что происходит |
|---|---|
| **«запиши идею: …»** | идея уезжает в `BACKLOG.md` → «📥 Входящие» с датой |
| **«недельный заезд»** | ассистент читает файлы протокола, реализует приоритеты, поднимает версию, пишет WEEKLY-заметку, прогоняет все тесты |
| **«сделай сейчас: …»** | реализуется немедленно, версия поднимается как PATCH/MINOR |
| **«что у нас по плану?»** | сводка backlog по приоритетам + что сделано в последней версии |
| **«сделай бекап себя»** | обновляется `HANDOFF.md` (+ копия в `HANDOFF/archive/`) |
