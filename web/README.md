# HabitVerse 2.1 — основной проект (Next.js)

🟢 **Это продакшен-версия HabitVerse** (версия 2.1.0, 2026-10-09; релиз 2.0.0 — 2026-10-08):
полноценный перенос v2-дизайна
из одностраничного демо (`../v2`, эталон `../HabitVerse-2.0.html`) в многостраничный сайт.
`../app` (v1.2 + Supabase) — архив и донор Supabase-слоя для фазы 5.4; план — `../docs/PORT_PLAN.md`.
Пользовательская инструкция (запуск, деплой, бэкап) — `../ИНСТРУКЦИЯ.md`.

## Запуск
```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck  # tsc --noEmit
npm run build      # серверная сборка: next build --webpack (Turbopack в песочнице ловит SIGKILL)
npm run start      # раздать серверную сборку
npm run export     # HV_EXPORT=1 → статический сайт в out/ (любой хостинг; маршруты = папки с index.html)
```

Тесты (из соседней папки):
```bash
cd ../tests && npm run test:web          # 89 проверок: engine.ts + md.ts + presets.ts (компилирует TS сам)
cd ../tests && npm run test:web:smoke    # 62 проверки: jsdom С гидратацией против серверной СБОРКИ
                                         # (нужен свежий npm run build; поднимает next start на своём порту)
cd ../tests && npm run test:web:static   # 6 проверок: статический экспорт (нужен свежий npm run export)
```

## Что здесь есть (2.1.0)
- **Каркас (5.1):** 8 маршрутов, Shell (шапка, сайдбар, breadcrumbs, темы 8×2, плотность), ⌘K, тосты,
  дизайн-токены и CSS из `v2/styles.css`, SVG-иконки, аватары-инициалы.
- **Движок (5.2, расширен в 5.3 и 2.1.0):** `src/lib/engine.ts` — чистые функции (расписание, стрики,
  заморозки «правило двух дней», недельные квоты, консистентность, CRUD привычек/заметок/челленджей,
  лента и реакции, CSV, seedDemo с командой и расходами, normalize). **Финансы (2.1.0):** `Expense`,
  `finPeriod/finShift/finLabel/finSummary/fmtMoney/add-update-removeExpense/buildExpensesCsv`,
  12 пресетов `EXPENSE_TYPES`; семантика расчётов — `../HANDOFF.md` §4 «Финансы» (закреплена тестами). В web-движке исправлен баг демо B-1 (двойной счёт сегодняшней
  отметки в стрике) — см. `../BACKLOG.md`.
- **Данные (5.2):** `src/lib/store.ts` — localStorage-ключ `habitverse.v1` (та же схема, что у демо:
  экспорт/импорт совместимы), `useSyncExternalStore`, гидратация без SSR-mismatch,
  `hv.importJson` — восстановление из JSON-бэкапа (кнопка «Импорт JSON» в Настройках).
  ⚠️ `mutate()` меняет ссылку только на верхний объект state — зависимости useMemo писать на `[state]` (грабля №53).
- **Все разделы (5.3):**
  - `/` Обзор (метрики, «На сегодня» с циклом отметок, полоса недели, стрики, мысль дня, сводка);
  - `/habits` — фильтры со счётчиками, поиск, строки привычек (история/квоты/заморозки/weekdots),
    инлайн-переименование, ⋯-меню, **DnD-сортировка за ручку** (Pointer Events, мышь+палец);
  - `/calendar` — сетка месяца (точки статусов, %-дня), панель дня с отметками за любые прошедшие даты,
    шит «день × привычка» (количество/заметка/статусы), heatmap года, сводка месяца, `?month=&day=`;
  - `/reports` — диапазоны 7–365, 5 KPI с дельтой, 4 canvas-чарта (`src/lib/charts.ts`), рейтинг, стрики,
    карта года, инсайты, CSV, печать;
  - `/notes` — md2-разметка (`src/lib/md.ts`), сетка карточек, поиск/теги/pin, модалка редактора, `?new=1&open=`;
  - `/team` — челленджи (карточки/создание/код/шит с heatmap), лидерборд за 30 дней, экипаж, лента
    с реакциями; демо-режим (экипаж смоделирован), реальные друзья — фаза 5.4;
  - `/finance` — **F-2 «Финансы» (2.1.0):** реестр-таблица «дата/тип/наименование/сумма» с быстрой
    формой (Excel-поведение), итоги день/неделя/месяц (чипы + стрелки + «Текущий»), 4 KPI,
    **пьедестал 2-1-3** с цитатами пользователя, разбивка по типам, названия по убыванию, экспорт CSV,
    модалка записи (`expense-modal.tsx`); `?new=1&period=`;
  - `/settings` — имя (аватар-инициалы), демо-данные, **экспорт/импорт JSON-бэкапа**, сброс;
    полный профиль — 5.4.
- **Каталог пресетов (5.3):** `src/lib/presets.ts` (30 привычек в 7 группах) + модалка в Shell;
  открытие: сайдбар «Быстрые действия → Каталог», кнопки страниц, ⌘K, событие `hv:open-catalog`.
- **F-3 (отзыв Максима):** `src/components/notes-widget.tsx` — плавающая иконка заметок на всех страницах,
  hover → закреплённые + свежие (≤6), тап фиксирует панель, клик ведёт в `/notes?open=<id>`.
- **F-2, второе размещение (2.1.0):** чип «Реестр трат» в строке привычки категории «Финансы»,

- **Онбординг (2.1.0):** `src/components/onboarding.tsx` — 4 шага (приветствие → имя → аватар-эмодзи →

- **⌘K (5.3, расширен в 2.1.0):** разделы, «Создать» (привычка/**запись расходов**/каталог/заметка/
  челлендж), поиск по привычкам (`?focus=`) и заметкам (`?open=`), оформление, «Данные» (демо/экспорт JSON/CSV).
- **Продакшен (2.0.0):** серверная сборка + статический экспорт (`next.config.ts` переключается
